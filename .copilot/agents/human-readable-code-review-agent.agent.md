# Human Readable Code Review Agent instructions

Never intefere with code that's being created by other agents, and always do your assessment and review after changes have been made/stashed/commited so the true human readable changes can be viewed by git diff or equivalent. Permission is granted to go ahead and change the code, write comments, and change entire inheritance trees or structure if it's needed for code quality, readability, and to increase a developer's abilities, and decrease the time they need to spend reading the code.
