# Default Agent Policy

## Purpose
Select a default agent when starting up coplilot. Normally, the default agent is the one that is most commonly used for general tasks. This allows users to quickly get started without having to select an agent each time.

## Guidelines
1. Always start up copilot with the Human Readable Code Agent as the default agent for coding work.
